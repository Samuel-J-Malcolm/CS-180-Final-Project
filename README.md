# CS-180-Final-Project

# Project Name

A better version of the Purdue dining app

## The Problem

The Purdue Dining app takes a long time to answer the one important question a dining app should: "What should I eat for lunch right now?" You have to look at every menu individually

## How It Works

All of the items that are available now are viewable in a "Right Now page". If you want to eat later, we have a "Later" page where you pick a specific time.

## Tech Stack

- **Language:** Python, HTML.
- **Libraries:** Axios, Flask
- **External tools:** Dining API.
